# Aditya Pande — 3D Developer Portfolio

An immersive, interactive developer portfolio built with **Next.js 16**, **React Three Fiber**, and **Tailwind CSS v4**. Features a 3D mechanical keyboard hero scene with verified Backend & DevOps tech stack icons, seasonal themes, smooth scroll animations, bilingual support (English & Hinglish), and an interactive contact modal.

## Highlights

- **Interactive 3D Mechanical Keyboard** — Built with React Three Fiber, Three.js, and Simple Icons. Features keycaps with authentic backend & cloud technologies (Node.js, Express.js, MongoDB, React, Next.js, Docker, Kubernetes, Linux, Nginx, Terraform, Jenkins, Helm, GitHub Actions, Git, TypeScript) reacting to live keypresses and scroll interactions.
- **Hero & Identity** — Prominent bold typography highlighting Aditya Pande's background as a Backend Developer & DevOps Engineer with isolated portrait presentation.
- **Featured Projects Showcase:**
  - **SolivaGuard — Production E-Commerce Platform & Admin Dashboard** — Live full-stack platform with Node.js/Express REST APIs, MongoDB, Razorpay payments, Docker, AWS, Linux, Nginx, and GitHub Actions CI/CD.
  - **Multi-Tier Kubernetes Deployment (DevOps Project)** — Robot Shop microservices deployed on AWS EKS with Kubernetes manifests, Helm charts, Ingress routing, and automated Jenkins/GitHub Actions pipelines.
  - **Kinetic Care Gym (Client Landing Page)** — Mobile-first promotional page with focused visitor onboarding and WhatsApp enquiry flow.
  - **Jainism Cake & Cafe (Client Website)** — Customer-facing bakery & cafe website presenting menu highlights, cakes showcase, and booking UX.
  - **Interactive 3D Shopping Experience** — 3D product exploration built with React.js, Three.js, React Three Fiber, and GSAP.
- **Interactive Contact Modal:**
  - **Hiring & Other:** Synchronously transfers visitors directly to Google Gmail web compose with pre-filled subject and inquiry details.
  - **Project Inquiries:** Dispatches project collaboration inquiries to `/api/contact` and displays an inquiry confirmation screen.
- **Bilingual Experience (EN / Hinglish)** — Seamless toggle between English and natural Hinglish.
- **Smooth Scroll & Micro-interactions** — Powered by [Lenis](https://github.com/darkroomengineering/lenis) with custom cursor and magnetic hover effects.

## Getting Started

### Prerequisites

- **Node.js** 20+
- **npm** 10+

### Installation & Local Setup

```bash
# Clone the repository
git clone https://github.com/adi-Git-Hub/portfolio-urwashi.git
cd portfolio-urwashi

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm start
```

### Docker

```bash
docker build -t portfolio-aditya .
docker run -p 3000:3000 portfolio-aditya
```
